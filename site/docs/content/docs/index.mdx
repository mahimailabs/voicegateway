---
title: What is VoiceGateway
description: See one LiveKit voice call from the phone line to the model.
---

<Picture src="/diagrams/call-path" alt="A call goes from the phone through the LiveKit media server to the voice agent and its models. VoiceGateway sits to the side and receives webhooks, metrics, spans and session uploads." />

A voice call passes through many parts. VoiceGateway shows all of them on one timeline, so you can see where a call got slow or went wrong.

It watches from the side. If VoiceGateway stops, your calls keep going.
