| You see | It comes from |
| --- | --- |
| Load and active jobs per worker | The worker's own metrics page |
| Agents and versions on LiveKit Cloud | LiveKit Cloud |
| CPU and memory of a self-hosted worker | cAdvisor, for a container you map |

Add a self-hosted worker's metrics address:

```bash
voicegateway project workers add http://agent-host:8081/metrics --project production
```

Map a worker's container to read its CPU and memory:

```bash
voicegateway project resources add --org default --project production --kind worker --target worker-a --container /docker/<container-id>
```

[Container CPU and memory](https://github.com/mahimailabs/voicegateway/blob/main/docs/container-resources.md) has the cAdvisor setup. A source that has not answered shows as awaiting samples or stale, never as idle.
