<Picture src="/screens/live" ext="jpg" alt="The Live page: one bar per room on a five-minute timeline, the open room in blue." />

Each room is a bar that grows while it is open. Click one to open its call.

The worker pushes each change to the page as it stores it. Every source shows when it was last read: a source that stops answering is marked stale, never shown as idle, and the page catches up when it reconnects.
