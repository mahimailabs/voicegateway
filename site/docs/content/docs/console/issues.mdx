<Picture src="/screens/issues" ext="jpg" alt="The Issues page: open issues by severity, each with its source, how many calls it was seen on and when it was last seen." />

VoiceGateway checks every call and every layer. A problem seen on many calls becomes one issue, with the calls it was found on as evidence.

| You can | What happens |
| --- | --- |
| Resolve | It moves to Resolved. If it is found again, it shows as **Regressed** |
| Ignore | It moves to Ignored and stops counting as open |
| Tag | Group issues your own way |
| Archive | It leaves the list; Restore brings it back |

Pick several rows to change them together, and Undo straight after. A Member or an Admin can change issues; a Viewer can read them.
