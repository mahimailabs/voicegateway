<Callout type="warn">Preview. The rules work on your data today; sending notifications comes next.</Callout>

| Rule | Fires when |
| --- | --- |
| Slow answers | Answer time passes your budget |
| Replies cut off | The caller talks over the agent and it stops |
| Agent job failed | LiveKit reports an agent job as failed |
| Slow agent join | The agent takes too long to join the room |
| Unencrypted phone leg | A SIP trunk carries audio as plain RTP |
| Recording lost | An egress recording fails to upload |
| Ingress error | An ingress endpoint goes into error |

An alert resolves after 30 minutes or 5 good calls.
