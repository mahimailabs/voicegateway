Open Settings from the sidebar, or press <kbd>Ctrl</kbd> <kbd>,</kbd> (<kbd>⌘</kbd> <kbd>,</kbd> on a Mac) anywhere.

<Picture src="/screens/settings-thresholds" ext="jpg" alt="Settings, Thresholds: answer time 1.5 seconds, agent join 2 seconds and speech start 1 second, with Reset to defaults and Save changes." />

| Page | What it holds |
| --- | --- |
| Integrations | Where alerts will go: Slack, Teams, Discord, PagerDuty, Opsgenie, email, webhook |
| Connection | The two URLs your agent and LiveKit need, and whether each one works |
| Embeds | Signed widgets for your own pages, see [Embeds](/team/embeds) |
| Data | Recordings and how long each kind of data is kept |
| Thresholds | The budgets every page judges calls against |
| Organisation | Its projects |
| Access | People, API keys and coding agents |
| Your account | Your name, password and linked sign-ins |

## Thresholds

Thresholds are settings, not measurements. Change one and every page, check and issue uses the new number. A Member or an Admin can change them, and Undo puts the old ones back.

## Data

<Picture src="/screens/settings-data" ext="jpg" alt="Settings, Data: how many calls have a recording, where recordings are stored, and how long transcripts, traces and recordings are kept." />

Raw call data and recordings are deleted after 90 days. The call list and its summaries stay.
