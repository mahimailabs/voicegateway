---
title: Install
description: One command starts the whole platform on your own machine.
---

<Picture src="/diagrams/architecture" alt="One Go binary runs as web and worker, with Postgres, an S3 bucket, Redis and ClickHouse beside it." />

You need Docker, git, make and 10 GB of free disk.

<Steps>
<Step>

### Start it

```bash
git clone https://github.com/mahimailabs/voicegateway.git
cd voicegateway
make up
make preflight
```

The first run writes `deploy/.env` with fresh random secrets. Keep that file.

</Step>
<Step>

### Create the first admin

```bash
make user-add EMAIL=you@example.com
```

Sign in at [localhost:8080](http://localhost:8080).

</Step>
</Steps>

`make down` stops it and keeps your data. The [full self-hosting guide](https://github.com/mahimailabs/voicegateway/blob/main/docs/self-hosting.md) covers ports, HTTPS and upgrades.
