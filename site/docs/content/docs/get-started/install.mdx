---
title: Install
description: One command starts the whole platform on your own machine.
---

<Picture src="/diagrams/architecture" alt="One Go binary runs as web and worker, with Postgres, an S3 bucket, Redis and ClickHouse beside it." />

You need Docker and git.

<Steps>
<Step>

### Get the code

```bash
git clone https://github.com/mahimailabs/voicegateway.git
cd voicegateway
```

</Step>
<Step>

### Start it

```bash
make up
```

The first run writes `deploy/.env` with fresh random passwords. Keep that file safe.

</Step>
<Step>

### Create the first admin

```bash
docker compose -f deploy/compose.yaml --env-file deploy/.env exec web voicegateway user add --admin --email you@example.com
```

It asks for a password.

</Step>
</Steps>

`make down` stops it. Your data stays.
