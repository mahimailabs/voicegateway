---
title: Command line
description: Every voicegateway command.
---

| Command | Does |
| --- | --- |
| `voicegateway web` | Takes data in and serves the API |
| `voicegateway worker` | Turns data into calls and stores it |
| `voicegateway migrate` | Applies database migrations |
| `voicegateway preflight` | Checks every dependency answers |
| `voicegateway project add` | Adds a LiveKit project |
| `voicegateway project workers add` | Adds an agent worker's metrics address |
| `voicegateway user add` | Adds a person to an organisation |
| `voicegateway user reset-password` | Sets a new password |
| `voicegateway key create` | Creates a project API key |
| `voicegateway key revoke` | Revokes a project API key |

Add `--help` to any command for its flags.
